# Body Surface Area (BSA) Calculations in Healthcare

Body Surface Area calculations are essential for many medications, particularly chemotherapy and some pediatric drugs. This guide covers the main formulas and their applications.

## Why BSA Matters

BSA provides a more accurate dosing method than weight alone for certain medications because it:
- Better correlates with metabolic rate
- Accounts for both height and weight
- Provides more consistent dosing across body types

## BSA Formulas

### 1. Mosteller Formula (Most Common)

```
BSA (m²) = √[(Height in cm × Weight in kg) / 3600]
```

**Example**:
- Height: 170 cm
- Weight: 70 kg
- BSA = √[(170 × 70) / 3600] = √[11,900 / 3600] = √3.31 = 1.82 m²

### 2. DuBois Formula

```
BSA (m²) = 0.007184 × Height^0.725 × Weight^0.425
```

### 3. Haycock Formula (Pediatric)

```
BSA (m²) = 0.024265 × Height^0.3964 × Weight^0.5378
```

## Chemotherapy Dosing

### Calculating Chemotherapy Doses

```
Dose = BSA (m²) × Dose per m²
```

**Example**:
- Drug order: Carboplatin 400 mg/m²
- Patient BSA: 1.82 m²
- Dose = 1.82 × 400 = 728 mg

### Dose Capping

Many protocols cap BSA at 2.0 m² for safety:
- If calculated BSA > 2.0, use 2.0 for dosing
- Always check protocol-specific caps

## Practice Calculations

### Problem 1: Calculate BSA and Dose
- Height: 165 cm, Weight: 65 kg
- Order: Doxorubicin 60 mg/m²

**Solution**:
- BSA = √[(165 × 65) / 3600] = 1.73 m²
- Dose = 1.73 × 60 = 103.8 mg

## Quick Reference

### Average BSA Values
- Newborn: 0.25 m²
- 1 year: 0.45 m²
- 5 years: 0.75 m²
- 10 years: 1.15 m²
- Adult female: 1.6 m²
- Adult male: 1.9 m²

## Safety Considerations

1. **Always recalculate** with weight changes > 10%
2. **Verify formula** used by your institution
3. **Check dose limits** in protocols
4. **Round appropriately** based on drug guidelines
